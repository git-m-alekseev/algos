# Задача о разрезании стержня

Задача о разрезании стержня заключается в том, чтобы определить оптимальный способ разрезания стержня заданной длины на части, чтобы максимизировать прибыль от продажи этих частей. Каждый возможный размер части имеет свою цену.

Дано:
- Целое число `n`, представляющее длину стержня.
- Массив `p[1..n]`, где `p[i]` - цена за часть длины `i`.

Надо найти:
- Максимальную прибыль, которую можно получить, разрезая стержень длины `n`.
- Максимальную прибыль для длины N будем хранить в массиве r[N]

## Кол-во способов разрезать стержень длины n
Если разрезание стержня осуществлять так: 
1) разрезаем на два  
2) первую часть откладываем
3) вторую часть кладем перед собой
4) возвращаемся в п.1

Тогда можно определить, что кол-во сопосбов разрезать стержень: 2^(n-1).  

Как это доказать? Оно равно кол-ву способов разбиения (композиции) натурального числа n на положительные слагаемые.  

Можно представить число n в виде последовательности единиц, например: 5 = 1 1 1 1 1  
Разрез можно представить, как вертикальную линию между ними: 1 1 | 1 1 1  
Кол-во разрезаний - это кол-во способов расставить вертикальные линии.  
Для числа n кол-во мест, где можно поставить вертикальную линию = n - 1.
И каждое из возможных разбиений получается расстановкой таких линий между единицами, например:
1) 1 1 | 1 1 1  - разбиение
2) 1 1 | 1 | 1 1 - еще одно возможное разбиение
3) 1 | 1 | 1 | 1 | 1 - еще одно

Можно представить промежутки между единицами как слоты: 1[]1[]1[]1[]1  
Каждый слот либо заполнен, либо нет. И каждое такое уникальное заполнение - одно из возможных разбиений.  
Можно вообще убрать единицы, и оставить слоты: [][][][][].  
А вместо черты ставить в них либо 1 (черта), либо 0 (отсутствие черты): `[0][1][1][0]`
Ну и можно еще больше упростить, убрав слоты: 0110. То есть это просто двоичное число с (n - 1) кол-вом битов.  
И сколько всего таких чисел может быть? Конечно: 2^(n-1)

## Алгоритм динамического программирования

### Находим подзадачи и структуру оптимального решения

Как решить задачу длины n, (то есть найти rn) имея решения для меньших длин?
Например, для n = 4:
```
r[3] = max(p[3], p[0] + r[2], p[1] + r[1], p[2] + r[0])
```
Для произвольного n:
```
r[n - 1] = max(p[n - 1], p[0] + r[n - 2], p[1] + r[n - 3], ..., p[n - 2] + r[0])
```

### Рекурсивное определение стоимости оптимального решения

```
CutRod(p, n):
    if n == 0:
        ret 0
    r = Int.MIN
    for i in 0 to n - 1:
        r = max(r, p[i] + CutRod(p, n - i - 1))
    ret r
```

### Реккурсивное с запоминанием
```
CutRod(p, n, memo):
    if n == 0:
        ret 0;
    if memo[n] > 0:
        ret memo[n]
    r = Int.MIN
    for i in 0..n:
        r = max(r, p[i] + CutRod(p, n - i - 1, memo)
    memo[n] = r
    ret r 
```

### Реккурсивное bottom-up с таблицей

`dp[i - 1]` - максимальная стоимость разбиения стержня длиной i
`dp[0] = p[0]`
`dp[i] = max by i (p[i] + dp[i - 1])` 

```
CutRod(p, n, dp):
    if n == 0:
        ret 0
      
    dp[0] = p[0]
    
    for i in 1..n:
        dp[i] = -1
        for j in 0..i:
            dp[i] = max(dp[i], p[j] + dp[i - j - 1])
            
    ret dp[n - 1]
```
